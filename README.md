# 💼 Smart Investment Advisor

An AI-powered investment advisor built with Streamlit that:
- Assesses your risk using fuzzy logic
- Recommends a portfolio using a genetic algorithm
- Provides natural-language investment advice

## 📦 Features

✅ Risk Level Detection  
✅ Asset Allocation Optimization  
✅ Financial Market Integration  
✅ Historical Trend Charts  
✅ Real-Time Portfolio Pie Charts  

## 🚀 How to Run

```bash
git clone https://github.com/yourusername/smart-investment-advisor.git
cd smart-investment-advisor
pip install -r requirements.txt
streamlit run main.py
